# Customer Churn Prediction

## Project Overview
Customer churn prediction is an important business problem that helps companies identify customers who are likely to stop using a service. By understanding churn behavior, businesses can improve customer retention strategies and reduce revenue loss.

This project analyzes customer behavior, subscription details, and service usage patterns to identify churn indicators and predict customers at risk of leaving.

---

## Objectives
The main goals of this project are:

- Understand the dataset structure and features  
- Clean and preprocess customer data  
- Perform Exploratory Data Analysis (EDA)  
- Create meaningful visualizations  
- Apply Feature Engineering techniques  
- Build and compare Machine Learning models  
- Generate business insights and recommendations  

---

## Dataset
The dataset used in this project is the Telco Customer Churn Dataset, which contains customer demographic information, account details, services subscribed to, billing information, and churn status.

### Features Included
- Customer demographics  
- Subscription services  
- Monthly and total charges  
- Contract type  
- Internet services  
- Payment methods  
- Customer churn status  

---

## Project Workflow

### 1. Data Collection & Understanding
- Loaded and explored the dataset  
- Identified data types and feature structure  
- Analyzed dataset dimensions and characteristics  

### 2. Data Cleaning & Preprocessing
- Handled missing values  
- Removed duplicate records  
- Converted incorrect data formats  
- Encoded categorical variables  

### 3. Feature Engineering
Created new features to better understand customer behavior, including:
- Customer loyalty categorization  
- Average monthly spending analysis  

### 4. Exploratory Data Analysis (EDA)
Performed statistical analysis to identify:
- Customer churn trends  
- High-risk customer segments  
- Behavioral patterns affecting churn  

### 5. Data Visualization
Created visualizations to better understand customer behavior:
- Churn distribution  
- Contract type vs churn  
- Monthly charges analysis  
- Correlation heatmap  
- Feature importance visualization  

### 6. Machine Learning Models
Built and compared multiple machine learning models:

- Logistic Regression  
- Decision Tree  
- Random Forest  
- XGBoost  

The models were evaluated using:
- Accuracy  
- Precision  
- Recall  
- F1-Score  

---

## Key Insights
- Customers with month-to-month contracts are more likely to churn.  
- Customers with higher monthly charges have a higher churn risk.  
- Long-term customers are less likely to leave the service.  
- Customer engagement strongly impacts retention.  

---

## Business Recommendations
Based on the analysis, the following recommendations were identified:

1. Encourage long-term contracts to improve retention.  
2. Provide personalized offers to high-risk customers.  
3. Reduce churn risk through customer engagement programs.  
4. Monitor customers with high monthly charges more closely.

## Conclusion
This project successfully applied the full Data Science workflow, from data understanding and preprocessing to predictive modeling and business insights generation.

The findings highlight the importance of customer behavior, pricing, and contract structure in customer retention. By leveraging machine learning models, businesses can proactively identify at-risk customers and improve retention strategies.
